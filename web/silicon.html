Build it yourself

Your own GDS in about two minutes

Yosys synthesizes, the Python placer places, KLayout draws. The same run happens in GitHub Actions for every release.

Chapter 14: From Verilog to silicon →
bash
sudo apt install -y yosys klayout   # synthesis + the layout viewer
pip install klayout numpy pillow    # KLayout's Python module for the renders
make silicon                        # PDK, synthesis, placement, GDS, pictures
klayout build/silicon/ps_s130.gds   # Display, Full Hierarchy to see inside cells
Layouts use the SkyWater SKY130 open PDK (Apache 2.0). Renders by KLayout. Placement by tools/silicon/place.py. Placed, not routed: clock tree, routing and sign-off are the next step (chapter 14).
